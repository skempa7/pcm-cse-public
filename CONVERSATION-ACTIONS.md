# Conversation and examination interaction repair — September 10, 2026

Introductions are handled as social turns, before broad fact-keyword selection or AI routing. They do not release concern/history facts or count as counseling. Onset-activity questions use explicitly authored activity facts; exposure, medication changes, diet and other background information no longer substitute for an activity at onset. Twelve copied setting prompts were corrected in the cases and corresponding written lessons. Unavailable activity detail is explicitly unavailable and does not create a negative finding.

The febrile-cough case now describes no previous similar episode in its prior-episode answer, associated fact contract, and written encounter/note. It no longer introduces pneumonia as the current diagnosis. Diagnostic-certainty challenges receive an uncertainty response without new clinical facts. Legacy attempts containing the old pneumonia sentence receive a clarification on subsequent requests; old transcript entries and saved grades are not rewritten.

Exam tiles now execute their explicitly named components with one click. Distinct tests have separate tiles; incompatible alternatives such as seated/supine SLR or one/all quadrants are not bundled. The redundant supplied-vitals review is excluded from the visible catalog; actual orthostatic measurement remains available. Completed findings appear briefly and remain in Record, including after reload. Clinical duration and evidence gates remain enforced. Action availability still uses disclosed complaint systems rather than hidden case expectations; rehearsal retains the full applicable catalog.

Validation: 72 case variants for the new conversation routes, 49 AI/delivery tests plus 27 existing language/demeanor tests, 72 public playable-path checks, four timing presets, and 82 action-tile component checks. Browser test used febrile cough: introduction, onset activity, prior episode, one-click examination, Record badge, reload, reduced motion, SOAP submission and displayed debrief; no JavaScript errors. AI routing and validation were tested without paid API requests, not through a live paid model call. The public build remains provider-free. Existing grading limitations are unchanged; this is not a comprehensive clinical validation or a guarantee against every future unmatched phrase.
